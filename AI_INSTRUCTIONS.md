# ABHINAV OS

## Project Overview

This is NOT a commercial portfolio.

This website is NOT designed to get freelance clients, jobs, or recruiters.

It is a personal digital operating system that represents the life, personality, hobbies, projects, memories and journey of Abhinav Sharma.

Every design decision must reinforce this philosophy.

The visitor should leave thinking:

"I genuinely feel like I know this person."

NOT

"This is a nice portfolio."

-------------------------------------------------------

## Core Theme

The entire website should resemble a Windows Terminal.

Not a hacker interface.

Not cyberpunk.

Not sci-fi.

A clean Windows Terminal running on Windows 11.

Dark background.

Green monochrome terminal text.

Minimal UI.

No neon overload.

No unnecessary glowing effects.

Elegant.

Calm.

Playful.

-------------------------------------------------------

## Visual Language

Keep the existing hero section.

Do NOT redesign the overall appearance.

Improve it only where necessary.

Use:

- black background
- green accent
- terminal window
- monospace typography
- blinking cursor
- terminal prompt
- smooth animations

Everything must look like commands executed inside one terminal session.

-------------------------------------------------------

## Design Philosophy

Every section must appear as a command executed inside the terminal.

Example:

$ whoami

$ history

$ ls projects/

$ cat hobbies.txt

$ gallery

$ now

$ future

Avoid traditional webpage section headings.

Avoid large banners.

Avoid cards that look like bootstrap cards.

Avoid modern portfolio clichés.

Everything should feel native to the terminal.

-------------------------------------------------------

## Personality

The website should reflect:

- energy
- humor
- creativity
- curiosity
- friendliness

Not seriousness.

Professional but playful.

The user should smile while exploring.

-------------------------------------------------------

## Animations

Animations should be subtle.

Terminal typing.

Cursor blinking.

Fade transitions.

Sliding terminal output.

Folder expanding.

No flashy animations.

No spinning 3D effects.

No unnecessary parallax.

-------------------------------------------------------

## Interactions

The visitor should feel like they are exploring a computer.

Folders should expand.

Commands should execute.

Some outputs should type themselves.

Buttons should feel like terminal actions.

Avoid traditional webpage interactions where possible.

-------------------------------------------------------

## Loading Screen

Before entering the website, show a fake boot sequence.

Example:

BOOTING ABHINAV OS...

Loading Memories...

████████░░░░

Loading Projects...

██████████████

Initializing Humor...

Initializing Energy...

Welcome.

Fade into the hero.

-------------------------------------------------------

## Humor

Humor should exist throughout the site.

Examples:

Random terminal messages.

Funny comments.

Unexpected outputs.

Never become cringe.

Never become childish.

Natural.

-------------------------------------------------------

## Hidden Features

Include easter eggs.

Example:

sudo reveal-secret

This unlocks a hidden terminal page.

Other hidden interactions are welcome.

-------------------------------------------------------

## Accessibility

Animations should respect reduced motion preferences.

Maintain strong contrast.

Readable typography.

Responsive.

Keyboard accessible.

-------------------------------------------------------

## Performance

Prioritize performance over fancy effects.

Avoid heavy animation libraries unless required.

Optimize assets.

Maintain smooth scrolling.

-------------------------------------------------------

## Important Rule

Never rewrite existing code unless necessary.

Modify the current project.

Preserve the existing architecture.

Preserve the existing hero design.

Build upon the current codebase.

-------------------------------------------------------

## NEVER DO

Do not convert this into a modern portfolio template.

Do not use glassmorphism.

Do not use floating blobs.

Do not use gradient backgrounds.

Do not use colorful UI.

Do not introduce random blue accents.

Do not redesign the terminal.

Do not replace the hero.

Do not add unnecessary sections.

Do not add client testimonials.

Do not add pricing.

Do not add resume download buttons.

Do not add skill percentage bars.

-------------------------------------------------------

## Final Goal

Build an experience.

Not a portfolio.

Visitors should feel like they explored Abhinav's personal operating system.
